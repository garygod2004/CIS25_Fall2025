# Cohort Manager Pro

Cohort Manager Pro is a C++ console application for managing a small class of students.  
It supports:

- Loading a **roster** from CSV  
- Tracking **attendance** with timestamps  
- Adding and storing **grades**  
- Generating **daily** and **overall** reports  
- Searching and sorting using **binary search** and **selection sort** (CIS 25 requirement)

This program was built as the **Final Project for CIS 25 – Intro to C++**.
